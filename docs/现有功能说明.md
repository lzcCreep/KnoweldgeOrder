# 知序现有功能说明

更新时间：2026-08-17  
当前桌面端版本：`0.1.0`

## 1. 产品定位

知序是一个本地优先的个人知识库。桌面端可以在没有后端的情况下保存笔记、待办、个人资料、设置和 Markdown/TXT 知识文件；登录后，再把支持同步的数据上传到 Spring Boot + PostgreSQL 云端。

“本地优先”表示保存动作先落到本机，云端不可用不会阻止本机保存。它不表示所有 AI 请求都天然离线：如果模型 URL 指向公网服务，发送给模型的参考资料也会离开本机。只有模型服务同样运行在本机时，才是完整断网 AI。

## 2. 两种运行模式

| 能力 | 本地离线模式 | 登录云端模式 |
| --- | --- | --- |
| 笔记增删改查 | 支持，先存本机 | 支持，先存本机再同步云端 |
| 今日待办 | 支持，先存本机 | 支持，先存本机再同步云端 |
| 分类 | 支持，分类定义保存在本机 | 笔记的分类名称随笔记同步 |
| 个人资料 | 保存到本机 | 显示名称、签名和空间名称同步云端 |
| Markdown/TXT | 保存、扫描、查看、编辑 | 本机保存后可选择上传云端 |
| AI 对话 | 本地关键词选材后直连已配置模型 | 后端用 pgvector 检索云端文档，再通过 LangChain4j 调用模型 |
| 云端 RAG / MCP | 不使用 | 语义 RAG 已接通；MCP 尚未接入对话链路 |

## 3. 已实现的界面功能

### 3.1 登录与离线入口

- 支持用户名、密码登录云端后端。
- 支持不登录直接进入本地知识库。
- 退出登录入口位于个人信息区域。
- 左侧状态会区分“云端已连接”和“本地离线模式”。

### 3.2 笔记

- 新建和编辑均在主页面完成，不使用弹窗。
- 笔记详情在主页面打开，不再使用右侧抽屉。
- 支持标题、正文、分类、收藏、删除和 Markdown 展示。
- 支持全部笔记、草稿箱、收藏、分类和搜索过滤。
- 每条笔记显示两个独立状态：
  - `本机知识库已保存`
  - `云端已同步`、`待上传云端`、`正在上传云端`、`云端上传失败`或`云端同步冲突`
- 云端 revision 冲突不会静默覆盖，界面提供采用本机版本或云端版本的选择。

### 3.3 首页与待办

- “今日回顾”从已有笔记中按日期轮换，不是固定假数据。
- “今日待办”支持添加、编辑、完成/恢复和删除。
- 待办与笔记相同，先保存本机；登录且存在知识空间时再同步云端。

### 3.4 分类、知识空间和个人资料

- 可以创建和删除本地分类。
- 删除分类时，原分类中的笔记会移到草稿箱，不删除笔记。
- 登录后可以创建、选择和改名云端知识空间。
- 个人资料在主页面编辑；离线时保存本机，登录时同步账户资料和当前空间名称。

### 3.5 知识库文件

- 设置中的默认目录为当前运行目录下的 `knowledge-files`，桌面端也可选择其他固定目录。
- 目前只接受 UTF-8 的 `.md`、`.markdown` 和 `.txt`。
- 点击“保存到知识库”后，文件先复制到本机目录，再根据云端配置决定是否上传。
- 打开“知识库文件”时会重新扫描目录，也可以手动点击“重新扫描”。
- 支持在主页面阅读和编辑文件，保存会直接写回原文件。
- Markdown 支持标题、列表、表格、代码块、链接和相对路径图片展示。
- 文件列表分别显示：
  - `知识库已保存`
  - `未上传云端`、`云端处理中`或`云端可检索`
- 本机文件与云端文档记录可以分别操作；删除云端记录不会删除本机原文件。

### 3.6 AI 管家

- 设置中可配置 OpenAI 兼容服务 URL、API Key、模型名、温度和最大输出。
- 配置保存在当前设备，不会写入 PostgreSQL。API Key 当前随本地设置以 JSON 形式保存，并未接入系统凭据保险库。
- 未配置模型时不会返回模拟 AI 答案，而是提示先配置。
- 桌面端 AI 面板可以拖动左边缘调整宽度，宽度保存在浏览器本地布局设置中。
- AI 回答的参考资料会区分：
  - `本机笔记 · 标题`
  - `本地文件 · 文件名`
  - `云端文件 · 文件名`

离线 AI 当前采用关键词匹配：从本机 SQLite 笔记和知识库目录的 Markdown/TXT 中选取相关内容，拼成上下文后直接请求配置的模型。不使用 pgvector、云端 RAG 或 MCP。

登录后的 AI 请求发给 Spring Boot 后端。`KnowledgeRetriever` 使用配置的 Embedding Model 将问题向量化，通过 pgvector Top-K 检索 `ready` 文档，并用 `owner_id`、`space_id` metadata 做权限隔离；检索片段和本机上下文随后交给带 `@SystemMessage`、`@UserMessage` 和 `@V` 的 `KnowledgeAssistant`，由 LangChain4j `AiServices` 和 `OpenAiChatModel` 调用用户配置的模型。

### 3.7 设置与版本通知

- 设置采用左侧分类、右侧内容的双栏布局，包含“账号”“通用”“AI 模型”“通知”和“关于”。
- “账号”显示登录状态、账号、当前知识空间和数据模式，并可进入个人资料编辑。
- “通用”管理知识库目录和知识文件自动上传；“AI 模型”管理 OpenAI 兼容模型参数。
- “通知”可以开关版本更新提醒；“关于”显示当前版本、发布日期和版本说明入口。
- 模型和应用设置会自动保存在当前设备，重新打开后继续使用。

### 3.8 桌面与手机

- Tauri 2 桌面端使用真实 SQLite 和本机文件系统。
- 手机浏览器和窄屏布局已经适配，核心笔记、待办、文件和 AI 界面可以使用。
- 手机浏览器目前不是 Android/iOS 原生安装包，也没有 PWA 离线启动缓存。
- 浏览器模式不能扫描任意系统目录，使用 `localStorage` 模拟本地数据和知识文件仓库。

## 4. 笔记到底保存在哪里

笔记不是保存成 TXT 文件。

### 4.1 Tauri 桌面端

笔记正文保存在 SQLite 的 `local_notes` 表中。开发环境数据库位置为：

```text
D:\KnowledgeOrder\database\zhixu.db
```

安装版优先使用 `<安装目录>\database\zhixu.db`。如果安装目录不可写（例如安装到受保护的 `Program Files`），会自动回退到 `%APPDATA%\com.zhixu.desktop\zhixu.db`。首次切换到新位置时会复制旧数据库及 WAL/SHM 辅助文件，旧文件仍保留作备份。

同一个 SQLite 文件还保存：

| 表 | 内容 |
| --- | --- |
| `local_notes` | 笔记标题、正文、分类、收藏、revision、同步状态和软删除时间 |
| `local_todos` | 今日待办及同步状态 |
| `sync_queue` | 等待上传或删除云端副本的笔记任务 |
| `settings` | 个人资料、应用设置、分类和设备 ID 等 JSON 配置 |
| `document_sources` | 云端文档 ID 与本机源文件路径的映射 |

知识库中的 `.md/.txt` 是另一类数据，直接保存在设置指定的文件夹，不写入 `local_notes`。

### 4.2 浏览器模式

浏览器没有 Tauri SQLite 权限，因此使用浏览器 `localStorage`：

- `zhixu-notes-v2`：笔记
- `zhixu-sync-queue`：笔记同步队列
- `zhixu-todos`：待办
- `zhixu-settings`：设置
- `zhixu-knowledge-files-v1`：浏览器内的知识文件内容

浏览器数据与桌面 SQLite 是两套本地存储，不会自动互相复制。

### 4.3 云端

登录后的云端副本保存在 PostgreSQL：

| 表 | 内容 |
| --- | --- |
| `users` / `auth_sessions` | 用户和会话 |
| `spaces` | 知识空间 |
| `notes_v1` | 云端笔记副本和 revision |
| `todos` | 云端待办副本 |
| `documents` | 云端文档元数据和当前完整文本 |
| `ingestion_jobs` | 文档处理状态 |
| `knowledge_embeddings` | 文档切块、向量及用户/空间/文档 metadata |

PostgreSQL 不是本机保存动作的前置条件。云端失败时，本机 SQLite 中的数据和同步任务仍然保留。

## 5. 本地模式笔记链路

```text
点击保存笔记
  -> 校验标题和正文
  -> INSERT/UPDATE local_notes
  -> SQLite 触发器写入 sync_queue
  -> 界面立即显示“本机知识库已保存 / 待上传云端”
  -> 离线模式到此结束
```

删除笔记采用软删除：`local_notes.deleted_at` 会先写入时间，并在同步队列中记录 `delete`。列表不再显示它，但在云端删除成功前，本机仍保留同步所需信息。

## 6. 云端模式笔记链路

```text
点击保存笔记
  -> 先执行完整的本地保存链路
  -> 客户端读取 sync_queue
  -> 调用 /api/v1/spaces/{spaceId}/notes 或 /api/v1/notes/{noteId}
  -> Spring Boot 写入 PostgreSQL notes_v1
  -> 返回新的 revision
  -> 更新 local_notes 为 synced
  -> 删除对应 sync_queue 任务
```

网络失败时任务保持 `pending/failed`，恢复网络或手动同步后重试。服务器返回 `409` 时进入冲突状态，由用户决定保留本机还是云端版本。

当前云同步仍是客户端逐条重放，不是完整的跨设备增量 push/pull 协议。新设备登录会拉取当前云端数据，但服务端游标、水位和批量同步仍待实现。

## 7. 当前明确未完成

- PDF、DOCX 等格式解析器尚未接入。
- 当前引用定位到文档级，尚未提供页码、chunk 高亮和相似度展示。
- MCP 尚未接入当前 AI 对话链路。
- 云端原文件仍使用服务器本地目录，尚未切换 MinIO/S3 对象存储。
- 跨设备增量游标同步、服务端批量 push/pull 尚未实现。
- 模型 API Key 仅保存在本机 SQLite/localStorage，尚未使用系统安全凭据存储。
- Android/iOS 原生安装包、PWA 离线启动和自动更新服务尚未完成。
