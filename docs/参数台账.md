# 项目参数台账

## 环境变量

`backend/src/main/resources/application.yml` 提供了本地默认值。推荐使用环境变量覆盖：

```text
DATABASE_URL=jdbc:postgresql://localhost:5432/testdb
DATABASE_USERNAME=postgres
DATABASE_PASSWORD=<本地密码>
SERVER_PORT=8080
PGVECTOR_HOST=localhost
PGVECTOR_PORT=5432
PGVECTOR_DATABASE=testdb
PGVECTOR_USER=postgres
PGVECTOR_PASSWORD=<本地密码>
PGVECTOR_TABLE=knowledge_embeddings
PGVECTOR_DIMENSION=1024
EMBEDDING_BASE_URL=http://localhost:8100/v1
EMBEDDING_API_KEY=not-required
EMBEDDING_MODEL=BAAI/bge-m3
RAG_CHUNK_SIZE=500
RAG_CHUNK_OVERLAP=80
RAG_RETRIEVAL_TOP_K=5
OPENAI_CHAT_MODEL=gpt-4o-mini
ZHIXU_BACKEND_URL=http://localhost:8080
ZHIXU_BACKEND_TIMEOUT_MS=5000
```

## Docker 参数

当前项目提供的 `backend/docker-compose.yml` 使用：

```text
服务名：postgres
镜像：pgvector/pgvector:0.8.6-pg18-trixie
宿主机端口：5432
容器端口：5432
数据库：testdb
用户：postgres
数据卷：zhixu-postgres
```

Embedding 服务由你单独下载的 Docker 服务提供，已知宿主机端口为 `8100`，接口为 `/v1/embeddings`。容器名称、镜像名称和容器内部端口尚未从 Docker Engine 查询确认，不在这里猜测。

## 变更规则

1. 修改端口、数据库、模型或维度时，先改 `application.yml`，再同步本台账和专题文档。
2. 修改 Embedding 模型或维度后，必须重建 `knowledge_embeddings` 并重新生成全部向量。
3. 修改 `RAG_CHUNK_SIZE` 或 `RAG_CHUNK_OVERLAP` 后，也应重新索引笔记，保证切块参数一致。
4. 密码禁止提交仓库，本地使用未跟踪的 `.env` 或系统环境变量。
