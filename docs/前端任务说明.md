# 前端任务说明

本文直接交给前端开发使用。公共事实来源是 [整体架构.md](整体架构.md)、[数据与文件策略.md](数据与文件策略.md) 和 [前后端接口契约.md](前后端接口契约.md)。

## 你负责什么

前端由 React + Tauri 组成，负责本地优先体验：

- SQLite 保存本地笔记、文件元数据、设置和同步队列。
- 用户可离线创建、编辑、删除和搜索笔记。
- 用户选择知识库文件目录并管理本机 Markdown/TXT。
- 自动扫描目录，页面内查看和编辑本机文件；桌面端也可用系统默认程序打开原件。
- 与后端同步业务对象，不上传整个 SQLite 文件。
- 展示云同步、文件解析、向量索引三个独立状态。
- AI 问答只调用后端；模型 URL/Key/模型名保存在当前设备，Key 仅在请求时发给本机后端转发。

## 数据状态必须分开

```ts
type SyncStatus = 'local' | 'pending' | 'syncing' | 'synced' | 'conflict' | 'failed'
type ParseStatus = 'none' | 'queued' | 'parsing' | 'ready' | 'failed'
type IndexStatus = 'none' | 'queued' | 'indexing' | 'ready' | 'failed'
```

界面文案必须准确：

- `synced`：已同步云端，不代表 AI 可以检索。
- `parseStatus=ready`：正文已提取，不代表向量完成。
- `indexStatus=ready`：才可以显示“AI 可检索”。
- 上传接口返回 `202`：只表示任务已接收，不表示已经进入向量库。

## 文件上传交互

1. 用户选择 Markdown/TXT 文件。
2. 先复制到知识库文件目录并立即加入本机列表。
3. 页面内预览或编辑，保存时直接写回文件。
4. 登录且开启同步时，再调用后端上传接口。
5. 调用后端上传接口。
6. 使用任务接口轮询，显示解析与索引状态。
7. 索引完成后才显示“可供 AI 使用”。

当前前端知识库文件支持 Markdown/TXT。PDF、DOCX 等解析器尚未接入，不出现在本机可编辑文件列表。

文件列表的查看动作：

- 有 `document_sources.local_path` 时启用“打开源文件”。
- 云端存在 document 时启用“查看提取文本”。
- 本地绝对路径不得同步给服务器或其他设备。

## 删除交互

不要只提供含义不明的“删除”按钮。菜单应提供：

- `移出 AI 知识库`：仅删除向量索引。
- `删除云端副本`：删除 PostgreSQL 副本和向量，本地保留。
- `删除本地记录`：SQLite 软删除，源文件是否删除需二次确认。
- `彻底删除`：本地、云端、向量、源文件全部删除，必须强确认。

在后端对应接口尚未完成前，只展示已实现的操作，并明确其范围。当前 `DELETE /api/v1/documents/{id}` 只是云端文档软删除。

## 前端调用边界

```text
允许：React/Tauri -> Spring Boot API
允许：React/Tauri -> SQLite、本地文件系统
禁止：React -> PostgreSQL
禁止：React -> pgvector SQL
禁止：React -> BGE-M3
禁止：React -> 云端 Chat Model 密钥
```

## 当前优先级

1. 接入服务端批量 push/pull 与跨设备增量 pull。
2. 完成知识文件三状态展示与任务轮询。
3. 完成四种删除范围 UI。
4. 需要原生手机安装包时初始化 Tauri Android/iOS 工程。
5. 用后端语义检索和结构化引用替换当前的“最近文档 + 本地笔记上下文”方式。

## 验收条件

- 断开后端仍能创建和编辑本地笔记。
- 联网后只同步 pending 变更。
- 文件页面能区分本地、云端、解析和索引状态。
- 不把“上传完成”显示成“向量完成”。
- 所有危险删除都显示实际影响范围并确认。
