# 本地数据库配置

知序最终采用两类业务存储：Tauri 桌面端使用 SQLite 保存本地数据；Spring Boot 使用 PostgreSQL 保存云端业务副本，并通过 pgvector 扩展保存 AI 检索索引。

## SQLite 本地库

| 配置 | 值 |
| --- | --- |
| 数据库文件 | `zhixu.db` |
| Windows 开发位置 | `D:\KnowledgeOrder\database\zhixu.db` |
| Windows 安装版位置 | `<安装目录>\database\zhixu.db` |
| 无写权限回退位置 | `%APPDATA%\com.zhixu.desktop\zhixu.db` |
| 当前表 | `local_notes`、`sync_queue`、`settings`、`document_sources` |
| 兼容表 | 旧 `notes` 表只作为迁移来源保留，不再全量覆盖写入 |

SQLite 不需要单独启动服务。客户端首次采用新路径且目标库不存在时，会把原应用数据目录中的数据库连同 `-wal` / `-shm` 文件复制过去，旧库保留作备份。桌面端笔记写入与 `sync_queue` 入队由 SQLite 触发器保证处于同一事务；本地记录使用稳定 UUID、revision、软删除和明确同步状态。当前客户端会通过既有单条笔记 API 顺序重放队列并显示 409 冲突，服务端批量 push/pull 与跨设备增量游标仍待实现。

## 当前环境

| 配置 | 值 |
| --- | --- |
| 数据库类型 | PostgreSQL 18 + pgvector 0.8.6 |
| Docker 镜像 | `pgvector/pgvector:0.8.6-pg18-trixie` |
| 地址 | `localhost` |
| 端口 | `5432` |
| 管理数据库 | `postgres` |
| 应用数据库 | `testdb` |
| 用户名 | `postgres` |
| 本地开发密码 | 仅通过 `DATABASE_PASSWORD` 配置，不提交仓库 |
| 向量扩展 | 已在 `testdb` 执行 `CREATE EXTENSION vector` |

项目后续统一使用 **pgvector**，不再使用 Qdrant。普通业务表和向量表都放在 `testdb`：

- `notes` 保存笔记原文、标签、来源等业务数据。
- `knowledge_embeddings` 保存 LangChain4j 切分后的文本、metadata 和 BGE-M3 生成的 1024 维向量。
- `documents.indexed_at` 只有在向量完整写入后才赋值；旧版本的假 `ready` 记录会在启动时自动进入重建任务。
- 原文以 `notes` 为准；向量数据可以从原文重新生成。

目标架构中，PostgreSQL 保存云端业务副本，pgvector 只保存可重建索引。大型 PDF/DOCX 原件不建议放数据库，保存到用户指定本地目录或对象存储。

## JDBC 连接

```text
jdbc:postgresql://localhost:5432/testdb
```

Spring Boot 默认配置已经写入 `application.yml`。本地可以直接运行，其他环境必须使用环境变量覆盖密码：

```text
DATABASE_URL=jdbc:postgresql://localhost:5432/testdb
DATABASE_USERNAME=postgres
DATABASE_PASSWORD=<本地密码>
PGVECTOR_HOST=localhost
PGVECTOR_PORT=5432
PGVECTOR_DATABASE=testdb
PGVECTOR_USER=postgres
PGVECTOR_PASSWORD=<本地密码>
```

## 检查命令

检查扩展是否安装：

```sql
select extname, extversion from pg_extension where extname = 'vector';
```

检查向量表：

```sql
select table_name from information_schema.tables where table_schema = 'public';
```

`knowledge_embeddings` 会在后端首次初始化 LangChain4j 的 `PgVectorEmbeddingStore` 时自动创建。默认 embedding 模型是 `BAAI/bge-m3`，维度为 `1024`；以后更换模型时必须同步修改 `PGVECTOR_DIMENSION` 并重建向量数据。

> 密码只通过环境变量或未提交的 `.env` 文件设置。仓库中的 `.env.example` 只提供占位模板。
