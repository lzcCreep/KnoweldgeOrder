## 已知技术债

- 后端仍使用 `schema.sql`，应迁移到 Flyway。
- 本地开发配置仍有弱默认密码，生产部署必须通过环境变量覆盖。
- `documents.content` 当前保存完整文本，未来需区分原件、解析文本和对象存储。
- 当前文档删除会清理向量并软删除云端记录，但尚未提供“只移出 AI/只删云端/彻底删除”的细分范围。
- 浏览器 localStorage 与桌面 SQLite 是各自本地事实来源，未登录时不会跨端共享；需由服务端增量 pull 完成跨设备同步。
- MCP `search_notes/get_note` 路径与真实后端 `/api/v1/spaces/...` 契约尚未一致。
