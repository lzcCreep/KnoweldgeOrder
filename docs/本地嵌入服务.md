# 本地 Embedding 服务

## 当前环境

| 配置 | 值 |
| --- | --- |
| 部署方式 | Docker 本地服务 |
| 模型 | `BAAI/bge-m3` |
| 宿主机地址 | `http://localhost:8100` |
| OpenAI 兼容端点 | `POST /v1/embeddings` |
| 完整请求地址 | `http://localhost:8100/v1/embeddings` |
| 输出维度 | `1024` |

用户提供的示例使用了 `localhost:8080`，项目约定的宿主机端口是 `8100`，所以后端和测试命令统一使用 `8100`。如果 Docker 实际没有发布到该端口，需要将容器映射调整为 `-p 127.0.0.1:8100:8080`，或按容器真实监听端口修改右侧端口。

## 测试请求

PowerShell 一行命令：

```powershell
curl.exe -X POST http://localhost:8100/v1/embeddings -H "Content-Type: application/json" -d "{\"input\":\"Hello, world!\",\"model\":\"BAAI/bge-m3\"}"
```

期望返回 OpenAI 兼容结构：

```json
{
  "object": "list",
  "data": [
    {
      "object": "embedding",
      "embedding": [0.0123, -0.0456],
      "index": 0
    }
  ],
  "model": "BAAI/bge-m3",
  "usage": {
    "prompt_tokens": 4,
    "total_tokens": 4
  }
}
```

实际 `embedding` 数组应包含 1024 个浮点数，文档示例仅保留两个数方便阅读。

## 后端配置

```text
EMBEDDING_BASE_URL=http://localhost:8100/v1
EMBEDDING_API_KEY=not-required
EMBEDDING_MODEL=BAAI/bge-m3
PGVECTOR_DIMENSION=1024
```

LangChain4j 使用 `OpenAiEmbeddingModel` 调用该服务，因为服务遵循 OpenAI Embeddings API 格式；这不代表使用了 OpenAI 的模型或把数据发送到 OpenAI。

更换模型时必须确认输出维度。模型或维度变化后，需要重建 `knowledge_embeddings` 并重新生成全部笔记向量，禁止混用不同模型生成的向量。
